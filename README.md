# CA-Lab-Azure-Data-Engineering
This repository contains the screenshots and documentation for the Cloud Architecture Lab experiments using Microsoft Azure.

Experiments
Experiment 1 – Azure Data Factory Pipeline
On-premises SQL database to Azure Blob Storage.
Experiment 2 – Azure Synapse Dedicated SQL Pool
Creation of a dedicated SQL pool and data loading.
Experiment 3 – Query and Analyze Data using Azure Synapse
Querying and analyzing structured and unstructured data from Azure Data Lake Storage.
