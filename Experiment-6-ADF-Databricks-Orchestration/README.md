# Experiment 6 – Azure Data Factory and Databricks Pipeline Orchestration

## Objective
To integrate Azure Data Factory with Azure Databricks for end-to-end data pipeline orchestration.

## Implementation
The experiment demonstrates the creation and execution of an Azure Data Factory pipeline for data ingestion and processing.

## Components Used
- Azure Data Factory
- Azure Databricks
- Azure Data Lake Storage Gen2
- Azure Key Vault
- Linked Services
- Datasets
- Copy Data Activity
- Pipeline

## Result
The Azure Data Factory pipeline was successfully validated and executed.
